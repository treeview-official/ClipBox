# 01. ClipBox 제품 기능 명세 (PRD v1.0)

## 1. 제품 목표
Windows 클립보드에서 복사한 내용을 로컬에 기록하고 전역 단축키로 빠르게 찾거나 재복사하는 경량 데스크톱 유틸리티.

대상 사용자: 개발자, 사무직, 문서 작업자. 로그인/서버/계정/동기화 기능 없음. 완전한 오프라인 사용을 우선한다.

## 2. 화면 및 작업 흐름
1. **최초 실행(온보딩):** 로컬 저장, 수집 대상(텍스트/링크/이미지), 민감정보 주의, 자동 시작/수집 허용 여부 안내. 기본 기록 설정을 사용자가 선택할 수 있어야 한다.
2. **백그라운드 모니터:** 사용자가 다른 프로그램에서 복사하면 새 내용을 감지해 저장. 앱 자체가 클립보드에 다시 복사하는 동작은 중복 기록을 만들지 않도록 처리.
3. **퀵 팝업:** 단축키로 열기 → 검색 필드 자동 포커스 → 필터/키보드로 항목 선택 → 클립보드에 재복사 → 필요시 사용자 Ctrl+V.
4. **기록 관리:** 전체/텍스트/이미지/링크/즐겨찾기 필터 → 검색 → 항목 선택 → 상세 정보 확인 → 재복사, 즐겨찾기 토글, 삭제.
5. **환경설정:** 자동 시작, 트레이 동작, 기록 일시정지, 단축키, 저장 개수, 보관 기간, 테마, 전체 삭제.

## 3. 필수 기능과 예외 규칙
### 3.1 클립보드 수집
- 앱 실행 중 OS 클립보드 변경 감지. Electron clipboard API를 사용하며 Windows 우선 최적화.
- 우선순위: 텍스트와 URL → 이미지. URL은 텍스트 중 URL 패턴에 부합하면 별도 필터로 분류하고 원문은 텍스트로 보존.
- 이미지: PNG 형식으로 앱 데이터 디렉터리에 저장하고 경로/해상도/크기 기록. 이미지가 너무 크거나 변환 실패 시 안전하게 제외하고 오류 기록(이미지 원문 로그는 금지).
- 동일 클립보드 상태가 여러 폴링에서 유지돼도 1회만 저장한다. 일정이 지난 후 사용자가 동일 내용을 **다시 명시적으로 복사**했는지 OS가 구분할 수 없는 케이스가 있으므로 완벽한 재복사 감지는 보장하지 않는다.
- 일시정지 상태일 때 수집 금지. 앱 시작 전 과거 기록 자동 복구 불가.
- 클립보드가 임시 잠금/빈 상태/지원되지 않는 형식일 때 앱이 죽지 않고 다음 감지를 시도한다.
- 클립보드 감지 주기 기본 약 400ms(예시)로 시작하고 성능 측정 후 조정할 것. 최대 이미지 데이터 변환을 불필요하게 반복하지 않는다.

### 3.2 항목 및 검색
- 아이템 정보: 원문(텍스트만), 저장 시간, 유형, 제목/미리보기, 해시, 즐겨찾기, 크기, 이미지 크기.
- 검색은 텍스트 및 URL을 대상으로 대소문자 구분 없이 실행. 입력 즉시 결과 갱신(간단 디바운스 가능).
- 정렬은 기본 최신 순. 즐겨찾기 필터와 즐겨찾기 토글 제공.
- 삭제 즉시 UI에서 사라지고, 이미지 파일도 참조가 없으면 삭제. 전체 삭제는 이중 확인. 기본 정책은 즐겨찾기 항목은 자동 정리 대상에서 제외하되 사용자가 직접 삭제 가능.
- 중복 해시가 동일한 내용을 각 폴링마다 누적하지 않는다. 명시적인 복사 감지가 가능하지 않은 이상 "사용자가 다시 복사한 횟수" 통계를 제공하지 않는다.

### 3.3 단축키
- 글로벌 팝업 단축키 기본 `Ctrl+Shift+V`; 충돌 시 등록 실패 안내 및 설정에서 변경 가능한 단축키 제공.
- 팝업 열 때 검색 입력란에 포커스, ↑/↓ 이동, Enter 선택 항목을 클립보드에 복사, Escape 닫기.
- `Ctrl+Enter`는 복사와 동일 동작. 자동 붙여넣기는 2차 구현으로 분리하고 Windows OS 연동이 검증된 경우에만 제공.
- 상세 화면의 복사/삭제/별표 액션은 키보드와 마우스 모두 제공. 접근성 라벨 적용.

### 3.4 트레이/종료
- 퀵 팝업 닫기 = 숨기기. 메인 창 닫기 동작은 설정에 따라 숨김(기본) 또는 종료.
- 트레이 메뉴: '빠른 기록 열기', '기록 관리', '수집 일시정지/재개', '환경설정', '완전 종료'.
- 종료 명령은 폴링, 단축키 등록, DB 리소스 정리 후 종료.

### 3.5 설정 기본값
- 최초 수집: 사전 안내 후 사용자가 활성화 (옵트인)
- 자동 실행: OFF (사용자 설정 시 ON)
- 트레이 상주: ON
- 저장 상한: 즐겨찾기 제외 1,000개
- 자동 보관: 즐겨찾기 제외 30일 (0/무제한 옵션을 두더라도 사용자에게 용량 경고)
- 이미지 단건 최대 10MB (초기 기본값)
- 테마: 시스템 테마 자동 감지; 수동 라이트/다크 전환 지원
- 앱 언어: 한국어

## 4. 범위 밖 (후속)
- 계정·로그인·클라우드 동기화·외부 서버
- 다중 PC 실시간 동기화
- 자동 붙여넣기를 위한 키보드 주입 (별도 실기기 검증 후)
- 출처 앱별 제외(Windows 네이티브 통합 필요) 및 보안 비밀 탐지 고도화
- 클립보드 파일/HTML/RTF 등 복합 서식 완전 지원
- 암호화/백업/동기화 및 데이터 이동 UI

## 5. 성공 조건
- Windows 환경에서 일반 복사 후 퀵 팝업을 통해 이전 내역을 재선택하고 정상적으로 복사할 수 있다.
- 앱 창을 닫아도 트레이에 상주하면서 수집(사용자 동의 이후)한다.
- 재실행 후 기록과 즐겨찾기가 유지된다.
- 검색/필터/삭제/보관기간/수집 일시정지가 정상 동작한다.
- 네트워크 연결 없이 실행할 수 있다.
