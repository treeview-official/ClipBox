# 05. Windows 수동/자동 QA 체크리스트

## 기본
- [ ] 첫 실행: 수집을 설명하고 사용자가 활성화하기 전까지 내용을 영속 저장하지 않는다.
- [ ] 메모장에서 텍스트 `hello world` 복사 → 기록 1개 생성.
- [ ] 아무것도 추가 복사하지 않은 상태에서 폴링이 돌아도 중복 기록 증가 없음.
- [ ] 브라우저에서 URL 복사 → 링크 유형 분류 및 올바른 재복사.
- [ ] Ctrl+C로 한국어/이모지/여러 줄 텍스트 복사 → 내용 손실/인코딩 문제 없음.
- [ ] 캡처 도구에서 이미지 복사 → 미리보기 정상, 재복사 후 다른 앱 붙여넣기 성공.
- [ ] 10MB를 넘는 이미지 → 앱이 멈추지 않고 건너뛰며 설명 제공.
- [ ] 감시 일시정지 → 새 복사 미기록, 재개 시 새 복사 기록.

## 퀵 팝업
- [ ] `Ctrl+Shift+V` 등록되면 다른 앱에서 열 수 있다.
- [ ] 단축키가 다른 앱과 충돌하면 안내가 표시되고 트레이에서 열 수 있다.
- [ ] 팝업이 열릴 때 검색창 자동 포커스, ↑/↓ 선택, Enter로 재복사, Esc 닫기.
- [ ] 다중 모니터/DPI 125%, 150%, 좁은 화면에서도 팝업이 화면 밖으로 나가지 않는다.
- [ ] 자동 붙여넣기가 없는 버전에서는 `Enter 붙여넣기`라고 잘못 표시되지 않는다.

## 데이터 안전성
- [ ] 재시작 후 기록/즐겨찾기 유지.
- [ ] 이미지 삭제 시 파일 정리, 잘못된 파일 경로 접근 차단.
- [ ] 개별 삭제/전체 삭제 확인 및 실제 삭제 확인.
- [ ] 자동 정리 시 즐겨찾기 유지.
- [ ] DB 파일 잠금/손상시 사용자에게 오류 표시하고 앱이 임의로 기록을 지우지 않는다.
- [ ] clipboard 내용이 콘솔/디버그 로그, 분석 SDK, 외부 URL로 전송되지 않는다.
- [ ] 비밀번호 제외 기능이 있다면 완벽한 감지라고 거짓 표시하지 않는다.

## 데스크톱 수명주기
- [ ] 창 닫아도 트레이에서 유지(기본 설정).
- [ ] 트레이 메뉴 일시정지, 기록 관리, 완전 종료 정상 동작.
- [ ] 앱을 두 번 실행해도 중복 감시 인스턴스가 생기지 않는다.
- [ ] Windows 부팅 자동 실행 토글이 실제 시작 프로그램에 반영된다(옵트인).
- [ ] 메모리/CPU 소비가 유휴 상태에서 과도하게 증가하지 않는다.
