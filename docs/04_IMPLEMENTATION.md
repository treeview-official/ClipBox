# 04. 구현 단계 및 수용 기준

## Phase 0 — 프로젝트와 기반
- Electron + React + TypeScript + Vite 초기화, 운영체제별 경로/환경분리.
- 루트 package.json 스크립트 dev / build / typecheck / test / make(or dist).
- Electron 보안 기본값, Preload IPC, 전역 에러 처리, 앱 단일 인스턴스 처리.
- 시각적 디자인 토큰, 공용 UI 컴포넌트 제작.

## Phase 1 — 로컬 기록 핵심 기능
- SQLite 연결/스키마 마이그레이션, 이미지 전용 폴더.
- 사용자 수집 동의/중지 UI.
- 텍스트/URL 클립보드 감시, 중복 억제, 검색, 즐겨찾기, 삭제, 보관 정책.
- 이미지 클립보드 저장/재복사/미리보기(지원 포맷, 용량 및 오류 처리).

## Phase 2 — 퀵 팝업, 트레이, 기록 관리
- 글로벌 단축키 열기/닫기, 창 포커스/검색 자동 포커스, 키보드 이동/복사.
- 기록 관리 3열 UI, 상세 미리보기, 유형 필터/카운트/검색.
- 트레이 상주, 재실행/종료/일시정지 메뉴.

## Phase 3 — 설정과 완성도
- Windows 시작 프로그램 설정, 사용자 지정 단축키, 보관 기간/상한, 라이트/다크.
- 전체 삭제 확인, 이미지 파일 정리, 오류 토스트, 빈 상태/접근성/단축키 충돌 상태.
- 스크린샷과 비교하여 레이아웃 시각 QA. 실제 목업에 있는 동작 문구와 구현 기능 불일치 수정.

## Phase 4 — 품질/패키징
- 유닛 테스트(검색, DB, 보관 정책, 중복 억제), UI 동작 검사.
- `npm run typecheck`, `npm test`, `npm run build` 실행 및 결과 정리.
- Windows EXE 설치 프로그램 빌드 구성, 앱 아이콘/메타정보/설치 및 제거 동작 확인.
- README: 설치/실행/비설치 개발모드/키보드 단축키/저장 위치/문제해결.

- [ ] 재시작 후 기록/즐겨찾기 보존
- [ ] 전역 단축키로 퀵 팝업 열고 검색 및 재복사
- [ ] 앱 창 닫아도 트레이에서 수집 지속 (동의 이후)
- [ ] 수집 일시정지와 재개가 즉시 적용
- [ ] 단축키 충돌 시 충돌 안내 및 우회 경로
- [ ] 보관 정책, 즐겨찾기 제외, 개별/전체 삭제 및 이미지 파일 정리
- [ ] 다크 모드/테마 변경 적용
- [ ] 보안 IPC 경계 및 외부 네트워크 없음 검증
- [ ] Windows EXE 빌드 과정 및 결과 검증 또는 환경 제약 기록
- [ ] 실행 방법과 알려진 한계 문서화
